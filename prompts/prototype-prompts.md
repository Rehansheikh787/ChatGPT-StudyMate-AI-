Design a modern mobile-first AI learning application called "StudyMate AI".

Goal:
Help JEE and NEET aspirants in India prepare more effectively while increasing daily engagement through personalized learning and proactive revision.

Target User:
High-school students (16–18 years old)
Preparing for JEE or NEET
Tier-1 cities in India

Core Product Concept:
An AI-powered study companion that acts like a personal tutor, revision coach, and exam mentor.

Design Principles:
- Duolingo-level engagement
- ChatGPT-level intelligence
- Clean and modern student-focused UI
- Minimal cognitive load
- Fast interactions
- Mobile-first experience

Create the following screens:

1. Onboarding
- Select Class (11th / 12th)
- Select Exam (JEE / NEET)
- Select Board (CBSE / ICSE)
- Choose Weak Subjects
- Set Exam Date

2. Home Dashboard
Show:
- Daily Streak
- Today's Revision Goal
- Study Progress
- Upcoming Exam Countdown
- Personalized Recommendations

Primary CTA:
"Start Today's Revision"

3. AI Tutor Chat
Features:
- Conversational chat
- Voice input
- Image upload
- Ask Doubts
- Explain Like I'm 15
- Step-by-step solutions

4. Quick Revision Screen
Features:
- Flashcards
- Micro quizzes
- Weak-topic revision
- Spaced repetition

5. Progress Dashboard
Show:
- Subject-wise mastery
- Weak topics
- Quiz performance
- Improvement trends

6. Gamification Layer
Show:
- XP points
- Levels
- Badges
- Study streak
- Weekly goals

7. Notification Center
Examples:
- Physics revision reminder
- Weak-topic challenge
- Daily streak alert

Visual Style:
- Premium EdTech product
- Inspired by Duolingo, Notion, and ChatGPT
- Modern cards
- Rounded corners
- Friendly academic illustrations
- Accessible typography

Output:
High-fidelity mobile app prototype with realistic screens and user flows.
