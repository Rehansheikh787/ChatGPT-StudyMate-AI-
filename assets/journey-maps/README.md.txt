# 🗺 User Journey Maps

This folder contains the user journey maps created during the Define phase of the product discovery process.

## Included

- Primary User Journey (JEE Aspirant)
- Secondary User Journey (CBSE Student)

These journey maps visualize the user's actions, thoughts, emotions, pain points, and opportunities across each stage of their interaction with ChatGPT.

The diagrams are based on the original case study and were generated using the prompts included in the project documentation.
